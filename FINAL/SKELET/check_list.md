
Полный интерактивный список параметров (Чек-лист для GUI / Меню)

На основе проведенных тестов и подтвержденных итераций сформирован полный перечень функций для настройки алгоритма под конкретный тип чертежа (РД/ИД):

1. Модуль предварительной подготовки (Препроцессинг)

• Очистка от исходного шума (Базовый Paint): Очищено вручную пользователем до запуска кода (Удаление штампов, лишнего текста, грязи). Результат: Кратное повышение точности алгоритма.
• Загрузка в Grayscale (Оптимизация ОЗУ): ВКЛ / ВЫКЛ. Чтение файла напрямую в 1 канал (IMREAD_GRAYSCALE) до апскейла. Результат: Защита от OutOfMemoryError.

2. Модуль масштабирования и субпиксельной плотности (Разрешение)

• Коэффициент масштабирования (Scale Factor): Выбор значения (x4 / x8 / x12 / x16 / x24). Результат: Увеличение частоты узловых точек.
• Метод интерполяции растра:
	• CUBIC (Бикубическая) — Быстрая, экономная по памяти, умеренная точность.
	• LANCZOS4 (Ланцош) — Тяжелая, субпиксельная точность округлостей шрифтов и стрелок.

3. Модуль управления ресурсами ПК (Отказоустойчивость)

• Тайлинг (Блочная обработка): ВКЛ / ВЫКЛ. Разбивка гигантского чертежа на изолированные сегменты (1200px / 1500px / 2000px).
• Принудительный Garbage Collection: ВКЛ / ВЫКЛ. Вызов gc.collect() после каждого блока для жесткой очистки ОЗУ.

4. Модуль выбора режима геометрии (Трассировка)

• Режим 1: Двойной контур (Морфологическая эрозия):
	• Формирует «жирный», внушительный чертеж для печати.
	• Минус: Сложно различим при сильном уменьшении масштаба масштабных схем.
	• Настройка: Количество итераций эрозии (от 2 до 10) для сближения/схлопывания внутренних стенок контура.
• Режим 2: Одиночный скелет (Центральная осевая линия):
	• Формирует тонкий, точный чертеж (99% копия оригинала), пригодный для инженеров.
	• Вызов нативной библиотеки утончения skimage.morphology.skeletonize.

5. Модуль оптимизации DXF под редактирование в AutoCAD

• Тип выходных CAD-примитивов (Режим Скелета):
	• Замкнутые полилинии (LWPOLYLINE) — Эталонный вид при печати. Минус: Автокад зависает намертво при команде ОБРЕЗАТЬ (_TRIM).
	• Разомкнутые отрезки (LINE) — Полная гибкость редактирования, Автокад не виснет. Минус: Слегка притормаживает из-за миллионов отдельных объектов.
• Уровень геометрического сжатия (CHAIN_APPROX):
	• NONE — Сохранение каждого пикселя. Файл весит критически много.
	• SIMPLE — Схлопывание прямых участков. Точки остаются только на углах.
• Допуск аппроксимации Дугласа-Пекера (Epsilon): Выбор значения (0.0 / 0.5 / 1.0 / 1.5). Выпрямление волнистости линий стен. Выше допуск — ровнее линии, но угловатее текст.

6. Модуль пост-фильтрации цифрового мусора

• Фильтр длины контура (Min Length): Игнорировать объекты короче (15 / 20 / 30 / 45) точек. Результат: Автоматическое удаление мелкой пыли и артефактов JPEG сжатия.
Этот структурированный перечень параметров полностью готов для интеграции в графический интерфейс (кнопки, чекбоксы и ползунки).
